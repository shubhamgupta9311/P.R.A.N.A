# Prototype Dataset

This dataset is a synthetic, illustrative footprint for the Upper Alaknanda pilot area in Chamoli, Uttarakhand. It provides enough varied habitation, risk, hazard-layer, and relocation-site records to exercise the dashboard workflow.

The population and all hazard, vulnerability, disaster-history, site-capacity, facility, and site-safety values are invented for demonstration. Village labels, coordinates, and hazard polygons are approximate UI anchors, not validated settlement locations or official hazard maps. Do not use these assessments to make real relocation, evacuation, land-use, or funding decisions.

Before operational use, replace the demo records with dated, sourced, field-verified data. Record source, collection date, spatial resolution, confidence, and responsible authority for each dataset. The rule-based risk calculation is a transparent prototype, not a trained predictive model.
